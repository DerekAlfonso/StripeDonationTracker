SETUP GUIDE ↗

Get ready
to give.

  1. Create a Stripe sandboxStart in test mode so no real money moves.
  2. Create a donation Payment LinkIn Stripe Payment Links, create a new link and choose “Customers choose what to pay.” Select a one-time USD payment and publish the link.
  3. Create a restricted keyIn Stripe Developers → API keys, create a restricted key for the same test mode. Grant read access to Payment Links, Prices, Checkout Sessions, Payment Intents, and Charges.
  4. Set Netlify environment variablesSet STRIPE_RESTRICTED_KEY to the restricted key and DASHBOARD_TOKEN to a long random secret, then redeploy.
  5. Connect and choose a linkEnter the dashboard token here, load active links, select your donation link, and save.
  6. Make a test donationOpen a generated share URL and use card 4242 4242 4242 4242, any future expiration date, and any CVC. The board updates on the next poll.
The board counts paid Checkout Sessions for the selected link. Pending or failed payments are excluded.
